## Pond Hopper

A Frogger-style arcade game made for phones: [`pond-hopper/index.html`](pond-hopper/index.html).

- Swipe on the board or use the on-screen pad to hop. Tapping the board hops forward.
- Keyboard: arrow keys or WASD, P to pause.
- Cross the road, ride the logs and turtles, and fill all five lily pads to reach the next level.

It is a single HTML file with no build step. Open it in any mobile browser, or enable GitHub Pages
for this repo and visit `/pond-hopper/` on your phone.
