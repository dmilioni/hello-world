## Penalty Bobbleheads

An arcade penalty shootout in a single file: [`penalty-bobbleheads/index.html`](penalty-bobbleheads/index.html).
Open it in a browser (or turn on GitHub Pages) and play.

- Player 1 is the shooter, Player 2 is the goalkeeper. Upload a face photo for each one on the start screen.
  Drag a photo to centre the face and use the zoom slider. "Pixel-arcade faces" gives them the chunky retro look.
- Each match is 5 penalties. Pick **Play as shooter** (you take the kicks, the computer keeps goal) or
  **Play as keeper** (you dive, the computer shoots). Score 3 or more and the shooter wins.
- Shooter controls: tap or press Space once to lock the direction, again to lock the height.
- Keeper controls: tap where you want to dive, or use the arrow keys (combine ← → with ↑ ↓ for corners).
- Photos stay in your browser. To bake faces in, add `penalty-bobbleheads/faces/player1.jpg` and
  `faces/player2.jpg` (only do that if you're happy for the photos to be public in this repo).
